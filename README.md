# Локальная проверка видео

Исследовательский сервис для кейса ForteBank. Код выполняет анализ локально; исходные видео, разметка, веса и результаты находятся в исключённой из Git папке `local/`. Название репозитория не является названием продукта.

Реализация в процессе. Готовность, качество и поддерживаемые типы будут указаны только после фактических измерений. Сейчас подтверждено: 42 исправных MOV, 40 уникальных записей, бинарные метки с точечными таймкодами; типов и интервалов в исходной разметке нет.

## Подготовка данных

Python 3.11 и FFmpeg должны быть доступны. В PowerShell из корня проекта:

```powershell
$env:PYTHONPATH='src'
python -m unittest discover -s tests -v
python -m cashframe.cli audit --videos D:\open\open\videos --labels D:\open\open\open_labels.xlsx
```

Команда сохраняет манифест и фиксированное разбиение по группам SHA-256 в `local/dataset`. Исходные видео и Excel не меняются. Почти одинаковые сцены требуют дополнительной проверки; разделение по точным дублям не доказывает независимость ракурсов.
