# Проверка интерфейса

В браузере выполнен сценарий на синтетическом двухсекундном MOV: выбор файла, ввод тестового ключа, фактическое состояние обработки, получение результата, выбор события, перемотка видео на секунду события, показ трёх декодируемых оригинальных JPEG и сохранение ручного подтверждения. Синтетическая сцена явно помечена; она не является результатом или оценкой модели.

Ширины: 1280 px и 390 px (узкий iframe с настоящими CSS media queries). Панели перестраиваются последовательно; на проверенном desktop нет горизонтального переполнения. Снимки локальные и исключены из Git. Приватные видео/кадры в визуальную проверку не передавались.

После исправлений reviewer: async результат фокусирует заголовок; клавиатурный выбор сохраняет фокус на выбранном событии; черновик и выбранное правило сохраняются в пределах своего события; новые события начинают с пустого правила. Полнота видимости обозначена как неоценённая; интервалы могут иметь sampled/incomplete/unknown, отсутствие метаданных даёт unknown.

Механический detector запускался один раз. Предупреждение об img относится к закрытому dialog, который получает JPEG только при открытии; предупреждение о плоской типографике вызвано разрешением runtime-пути CSS при статическом анализе. В действующем CSS размеры body/h1/h2 — 15/30/18 px. Полная проверка WCAG/контрастов и всех вспомогательных технологий не заявляется.
