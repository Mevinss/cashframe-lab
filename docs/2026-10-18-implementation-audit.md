## Что изменено

- Вердикт берётся из API. Для `violation`: «Обнаружены признаки возможных нарушений»; для `no_violation`: «Нарушение не обнаружено». История и предварительный PDF используют тот же исход.
- Из видимого интерфейса убраны CashFrame, Datathon и значок камеры. Функциональный заголовок — «Видеоаудит».
- Реализованы ru/kk/en и светлая/тёмная темы. Локальные настройки сохраняют язык/тему, но не API-ключ. Тексты сохранённых наблюдений и нормативных источников сохраняются на исходном языке с обозначением этого факта.
- Большой бордово-малиновый баннер содержит собственную объёмную видеокомпозицию с голубыми акцентами. Перемещение ограничено; работают мышь, касание, стрелки, Home и сброс. Основная кнопка неподвижна. Поддержан reduced motion.
- Worker сообщает измеренные количества обработанных выборок/кадров. Процент относится к текущему этапу; неизвестный объём остаётся неопределённым. 100% доступно только после сохранения готового результата. Строгий jury JSON не расширен.
- При неизвестной локализации не рисуется маркер нарушения на 0 секунде, не выполняется автоматический переход к 0; кадры явно обозначены контекстными. При открытии результата заголовок виден сразу.
- Защищённый `/api/v1/jobs/{job_id}/compliance` связывает наблюдения с исходным видео и единственным соответствующим событием. Неоднозначное пересечение не подтверждает несколько карточек. Подтверждение действия отделено от подтверждения применимости нормы.
- Карточка показывает исходный документ, раздел, ссылку, применимость, ограничения и автора наблюдения. Неподтверждённая связь остаётся предложением. Автоматического юридического классификатора нет.
- Подготовлены отдельная таблица событий и строгий импорт/экспорт. Оригинальная Excel-разметка не изменена. Переводы PDF входят в ключ неизменяемой ревизии; оригинальные JPEG не перекодируются для расчёта их хешей.

## Модели и обучение

Рабочий профиль — `local/experiment-v2`: замороженный DINOv2 ViT-S/14, оконная логистическая голова и kernel ridge классификатор видео. Прежние головы, конфиги и selected.npz сохранены. Исходная оконная голова обучалась 250 шагов Adam на 1 101 размеченном окне (39 положительных); источники разделены по группам 24/8/8, всего 40 уникальных видео. Энкодер не дообучался. Их хеши сверены с исходным снимком и сохранённым до спринта анализом.

Результат регрессии на прежнем test (8 источников, уже использовался ранее):

| Профиль | Accuracy | Precision | Recall | F1 | Specificity / FPR | TN / FP / FN / TP |
|---|---:|---:|---:|---:|---|---|
| Исходная голова | 50% | 50% | 100% | 66,7% | 0% / 100% | 0 / 4 / 0 / 4 |
| Активная v2 | 62,5% | 57,1% | 100% | 72,7% | 25% / 75% | 1 / 3 / 0 / 4 |

Это не новая независимая оценка и не подтверждение 85–90%. Один ответ меняет accuracy на 12,5 п.п.

Обучен отдельный слабонаблюдаемый локализатор на замороженных признаках: фон записи убирается по её собственным статистикам, используются остаточные/динамические признаки. Супервизия — окрестности размеченных точек и видео с отрицательной меткой; остальные моменты положительного ролика остаются неизвестными. Нормализация модели обучается на train. Архитектура/регуляризация выбирались по групповой train CV и validation. Первичная замороженная оценка на старом test помечена исследовательской; пересмотр ограничителя после диагностики train сохранён отдельным экспериментом без новой test-оценки.

После восстановления численной совместимости, при том же v2-бинарном фильтре:

| Validation, пять известных точек | Старая локализация | Кандидат |
|---|---:|---:|
| Найдено в пределах 2 секунд | 2/5 | 3/5 |
| Найдено в пределах 5 секунд | 4/5 | 3/5 |
| MAE среди локализованных точек | 1,625 с | 5,60 с |
| Локализованных предложений на отрицательных видео | 1 | 5 |

Улучшение неустойчиво, ложные предложения выросли. Кандидат **не включён по умолчанию**. Его изолированный профиль — `local/experiment-point-v1`.

Дополнительно выполнен ограниченный v3-эксперимент: 45 вариантов видео-дескрипторов/ядер с групповой CV, затем калибровка по validation и сравнение с реальной v2. Train CV accuracy 79,2% — статистика отбора, не независимая accuracy. Validation 50% против 62,5% у v2; требования допуска не пройдены. Test для этого эксперимента не открывался, замены нет.

Готовый TCN-код не запускался как fully supervised на выдуманных интервалах. Внешние датасеты не добавлены: коммерческая совместимость и перенос магазинных/валютных категорий на кассовую дисциплину должны быть подтверждены отдельно.

### X-13

Исходная точка 47 с сохранена. В старой голове все 132 окна превышали порог, поэтому ставился статус `unresolved` и контекст 0 с. Это не детекция нарушения в начале.

Экспериментальный профиль выдаёт шесть предложений, включая 46,5 с, но наиболее сильное — 35,5 с. Наличие близкой точки среди шести предложений не означает надёжную локализацию или классификацию. Рабочая v2 остаётся консервативно помеченной как нелокализованная; UI больше не выдаёт контекст за момент нарушения. Финальные HTTP-прогоны заняли 61,222 с для v2 и 37,317 с для экспериментального профиля; измеренная память worker — 204,9 и 342,3 МБ соответственно. Все три языка PDF/паспорта и их хеши проверены для обоих результатов. Разница времени одного прогона не доказывает ускорение модели.

### Численная совместимость

Проверка конечности раньше повышала float32-признаки до float64 перед mean/std, хотя замороженные головы обучались с исходной агрегацией. Восстановлена агрегация исходного dtype с сохранением проверки NaN/Inf. Равенство на FP64-границе сравнивается с фиксированным допуском 32 epsilon; это вычислительное правило, а не подбор порога по меткам. Новые калибровки используют ту же политику и sentinel выше допуска. Веса и сохранённые пороги не менялись. Эта политика и ограничения локализации включены в паспорт.

## Запуск и откат

Чистое окружение `.venv-isolated` не наследует глобальные пакеты. Установлены requirements.lock и CPU torch 2.6.0; `pip check` проходит. Прежняя `.venv` сохранена. На проверенной машине 7,7 ГБ RAM, GPU не использовался.

```powershell
cd D:\Datathon
.\scripts\start.ps1 -ModelDirectory local/experiment-v2 -EnvironmentDirectory .venv-isolated
```

Ключ — `local/api-key.txt`, через парольное поле или заголовок X-API-Key. Не помещать ключ в Git, URL или настройки браузера.

Для отдельной проверки кандидата, остановив текущий сервер либо выбрав другой порт:

```powershell
.\scripts\start.ps1 -Port 8002 -ModelDirectory local/experiment-point-v1 -EnvironmentDirectory .venv-isolated
```

Откат профиля — снова `local/experiment-v2`; исходная голова — `local/experiment`. Для новой установки отдельного окружения:

```powershell
.\scripts\setup.ps1 -Python311 'D:\Python 3.11\python.exe' -EnvironmentDirectory .venv-isolated
```

Проверка/конвертация отдельной таблицы (выходной JSONL должен быть новым):

```powershell
$env:PYTHONPATH='src'
.\.venv-isolated\Scripts\python.exe scripts/event_labels_table.py validate
```
