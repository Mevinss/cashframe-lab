# Запуск для команды

Репозиторий приватный: владелец должен дать коллегам доступ через GitHub → Settings → Collaborators. Само наличие ссылки не даёт доступ.

## На новой машине Windows

1. Установите Python 3.11 и FFmpeg с FFprobe, добавьте их в PATH.
2. Склонируйте `Mevinss/cashframe-lab` или распакуйте Download ZIP из GitHub.
3. Запустите `setup.cmd` и дождитесь сообщения `Environment ready`. Можно выполнить `scripts/setup.ps1` из PowerShell.
4. Получите у владельца подготовленные папки `local/encoder` и **весь выбранный профиль `local/experiment-v2`** по разрешённому приватному каналу. Положите их в `local/` своего проекта, сохранив структуру. Это текущая рабочая модель; перенос кода без этих артефактов не даёт готового анализа.
5. Запустите `.\scripts\start.ps1 -ModelDirectory local/experiment-v2 -EnvironmentDirectory .venv`, оставьте окно открытым и откройте <http://127.0.0.1:8000>. Если передана проверенная установка `.venv-isolated`, явно выберите `-EnvironmentDirectory .venv-isolated`. Для жюри не включайте `--dataset-review`.
6. Откройте `local/jury-access.txt`: там адрес сайта и действующий общий ключ этой установки. Введите ключ в интерфейсе один раз; браузер сохраняет защищённую сессию на 8 часов. API жюри использует тот же ключ в заголовке `X-API-Key`. Ключ не сохраняется в JavaScript или хранилище браузера. Каждая установка создаёт свой ключ; повторный запуск его сохраняет. Для остановки нажмите Ctrl+C в окне сервера.

Файл `local/jury-access.txt` содержит секрет: передавайте его только команде и жюри. Он и `local/api-key.txt` исключены из Git. Если ключ задан в окружении или `.env.local`, инструкция содержит именно этот действующий ключ. После перезапуска сервера браузер входит заново. Для доступа с другого компьютера сервер должен быть запущен с доступным сетевым адресом; адрес `127.0.0.1` работает только на самом сервере.

Для повторного запуска повторите команду с `-ModelDirectory local/experiment-v2`. Команда `start.cmd` без параметров сохраняет прежнюю совместимость и выбирает `local/experiment`; это первоначальная модель, а не активный профиль v2. Исходная обучающая выборка и Excel для анализа новых видео не требуются. Пока веса не установлены, интерфейс откроется, но `/health/ready` вернёт 503 и анализ не готов.

## Что передать вместе с кодом

На подготовленной машине владельца эти файлы уже находятся в `D:\Datathon\local`:

```text
local/
  encoder/
    encoder.json
    weights.pth
    source/           # исходники DINOv2, включая лицензии и hubconf.py
  experiment-v2/
    baseline.npz
    config-v1.json
    config.json
    report.json
    selected.npz
    selection-frozen.json
    trained.npz
    training-log.json
```

Переносите целиком `encoder` и `experiment-v2`, включая все восемь файлов модели выше. В частности, для v2 обязательны `selected.npz` и `selection-frozen.json`; копирование только трёх файлов первоначальной модели не подходит. Конфигурацию не редактируйте: она содержит настройки модели и контрольные суммы. Веса и их производные передаются только участникам с разрешённым доступом к материалам кейса. Не копируйте чужой `api-key.txt`, `jobs`, базу заданий, исходные видео, признаки или аннотации. Эти материалы не входят в Git. Сам GitHub-репозиторий не содержит готовых весов.

Если намеренно нужен первоначальный профиль v1, перенесите его отдельный каталог `local/experiment` и явно запустите `-ModelDirectory local/experiment`. Не смешивайте файлы разных профилей. Новые исследовательские головы не прошли проверку и не заменяют v2.

## Настройки

Конфигурация-пример находится в `.env.example`; личные `.env` и `.env.local` исключены из Git. Если `.env.local` ещё нет, скопируйте в него пример. Пустой ключ включает создание или повторное использование случайного `local/api-key.txt`.

```dotenv
CASHFRAME_HOST=127.0.0.1
CASHFRAME_PORT=8100
CASHFRAME_API_KEY=
```

В этом примере интерфейс откроется на <http://127.0.0.1:8100>. Ключ можно оставить пустым или задать собственный случайный секрет в `.env.local`/окружении. Если ключ задан явно, в интерфейсе используйте именно его, а не старый файл.

Приоритет: параметры `scripts/start.ps1 -Bind ... -Port ...` → переменные окружения → `.env.local` → `.env` → значения по умолчанию. Поддерживаются только три переменные выше, одна `ИМЯ=значение` на строку. Комментарии пишутся отдельными строками с `#`; кавычки вокруг значения допустимы. Подстановка `${...}` и выполнение команд не поддерживаются, значения читаются буквально.

У каждой установки свои веса, конфигурация и ключ. Для общего сервера команды настройте защищённый доступ по [инструкции размещения](deployment.md). Текущий командный HTTPS-адрес и обновление работающего экземпляра описаны в [инструкции синхронизации](sync-deployment.md). Участник, отвечающий за размещение, передаёт жюри фактический адрес и приватный `local/jury-access.md`; подготовка файла и проверка ключа описаны в [доступе к API](api-access.md). Сам GitHub содержит исходники и не перезапускает сайт.

Модель остаётся исследовательским прототипом с высоким числом ложных срабатываний: любой результат проверяет человек; перенос настроек и весов не улучшает её качество.
