Бинарная модель не выбирает юридическое основание по сходству изображения. Человек может сохранить наблюдаемый факт и предложенную связь через экран аннотации, после чего нужна отдельная проверка и размеченная оценка типа.

Приоритеты — редактируемая политика команды. Без подтверждённого типа и основания используется «не определён». Уверенность модели не подменяет приоритет.
