# Сверка с кейсом ForteBank — 18 октября 2026

Проверен файл `Кейс_ForteBank.docx`, включая разделы 4–10 и FAQ. Таблица ниже разделяет реализованный контракт и неподтверждённое качество распознавания. Работающий endpoint сам по себе не означает правильного определения нарушения.

## Сценарий и обязательный результат

| Пункт документа | Фактическое состояние |
|---|---|
| 4.1–2, 5: загрузка через сайт и статус обработки | Реализованы: MOV, запуск без ручной команды, этапы и измеренный прогресс, история заданий |
| 4.3, 5: два вердикта | В интерфейсе точные русские формулировки; в API только `violation` / `no_violation`, согласованные со списком событий |
| 4.4: несколько событий и их типы | Список поддержан; принятой модели типов нет. Неизвестный тип не заменяется выдуманной категорией |
| 4.4–5, 5: таймкод и соответствующий кадр | Есть предложения интервалов и исходные JPEG. Часть сигналов относится ко всему ролику: контекст не считается установленным моментом события |
| 4.6, 5: что видно и почему возможно нарушение | Классификатор пока даёт общий текст. Наблюдения человека сохраняются отдельно; это не автоматическое объяснение визуального действия |
| 4.7, 6: источник и связь с событием | Проверенный локальный реестр. Для точного известного типа показывается отдельный источник-кандидат, пункт, URL, условия и ограничения. Применимость не подтверждается названием класса; generic-сигнал не получает норму |
| 4.8, 10: API для жюри | Два заданных endpoint, multipart `file`, `job_id`, `processing` / `done` / `failed`, строгие имена полей и `X-API-Key` |
| 10: 1–3 JPEG в base64 | Успешный результат валидируется: base64 декодируется как полный JPEG; PNG, мусор и повреждённый JPEG отклоняются |
| 10: корректные временные метки | Типы времени конечны и неотрицательны; событие и кадры не выходят за длительность исходника, измеренную при загрузке. Неправильный результат становится `failed` без отрицательного вердикта |
| 10 / FAQ 14: не более пяти минут | Общий лимит задания 270 секунд, один worker. Ранее длинный ролик 142,53 с обрабатывался за 66,50 с, но с ложным срабатыванием; это не гарантия качества и скорости всех роликов новой машины |

## Что исправлено при этой сверке

- Проверка целостности JPEG, непустого типа/описания и временных границ на границе worker → API. Измеренная при загрузке длительность имеет приоритет над данными анализатора.
- Отдельные источники-кандидаты в веб-панели, PDF и Evidence Passport: точное сопоставление с локальным каталогом, условия на доступном языке, отсутствие утверждения о подтверждённом нарушении. У подтверждённого человеком основания остаётся прежний отдельный статус.
- Исправлено скрытие нормативных HTTPS-ссылок фильтром приватных путей. Каталоги учитываются в ревизии отчёта, поэтому после изменения условий старый PDF не выдаётся как новый.
- Исправлен приоритет ключа API-клиента: явный файл → эффективный ключ окружения/env → существующий локальный ключ. Проверка не создаёт и не меняет секрет.
- Исправлена передача модели: весь профиль v2 и энкодер вместо трёх файлов v1; production unit явно выбирает v2 и не включает приватную разметку.
- Добавлен `scripts/jury_preflight.py --base-url ...`: независимая проверка авторизации заголовком без cookie, готовности, сайта и выключения обучающей разметки. Отчёт не содержит ключей и приватных ответов.

## Ограничения и локальность

Раздел 7 и FAQ 21/27–29 запрещают облачные AI, передачу им видео/кадров/описаний и идентификацию лиц. Анализ использует локальные веса; исходящая сеть анализатора блокируется. Идентификаторы личности и распознавание лиц не добавлялись. Тестовые загрузки жюри не становятся обучающей выборкой; приватные веса, исходники, признаки, аннотации и ключ не входят в Git.

Качество обнаружения v2 — 62,5% на восьми знакомых видео. Дополнительные CPU-подходы дали 50%; голова действий — 0/5 на проверочных интервалах. Ни один кандидат не активирован. Надёжное определение типа, автоматическое описание конкретного действия и независимый новый ракурс остаются открытыми. Увеличение числа слоёв или заполнение поля `type` не закрывает эти требования.

Три выбранные категории для последующей подтверждённой разметки перечислены в [статусе классификации](jury-access-and-classification.md). Условия и границы выводов по источникам — в [нормативном аудите](2026-10-18-rules-quality-audit.md). Перечень автоматически подтверждённых юридических типов сейчас пуст.

## Передача и размещение

Публичный адрес настраивает другая участница команды. Локальный адрес не считается публичным URL; полный комплект сдачи до её развёртывания не готов. [Чеклист передачи](jury-checklist.md) включает явный выбор v2, приватную передачу весов, запуск без `--dataset-review`, создание ключа на целевой машине и внешнюю проверку MOV/API. Нельзя публиковать текущую установку с включённой разметкой и общим ключом жюри.

Программа проверена синтетическими тестами; они подтверждают контракт и защиту от некорректных ответов, а не качество модели. Полное соответствие кейсу, 80% точности и оценка 100 баллов не заявляются.
