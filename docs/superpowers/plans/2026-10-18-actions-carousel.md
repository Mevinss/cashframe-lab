# Visible actions and explanatory carousel implementation plan

**Goal:** Make the approved audit flow easier to use and research real local action labels without converting model guesses into ground truth.

**Architecture:** Keep binary v2 and the strict jury API. Add a protected visible-action catalog grounded in the existing local RK231 registry. Research SigLIP proposals locally in a separate assisted label table. Bound one additional train-only robustness experiment; gate candidates against frozen v2. Preserve the approved sculpture and add a controlled three-slide copy carousel. Exports move below the full-width verdict.

**Motion:** Three short explanations share one stationary upload action/sculpture. Pagination and arrows explain sequence; explicit pause and independent hover/focus/hidden/drag/view pause conditions prevent unwanted movement. Reduced motion starts paused; effects only transform/opacity within the banner, no background loops during analysis.

**Ownership and checks:**

- [x] Parent: official-source and dataset checks; action catalog/API with auth and applicability tests.
- [x] Local action worker: pinned public model, hashes, offline proposal inference, test excluded before decoding, separate automatic proposal/assisted CSV, abstention and no false confirmation.
- [x] Model worker: at most 18 train-only perturbation/mixup candidates, grouped OOF plus validation, no test access or active replacement.
- [x] Interface worker: carousel, translated controls/action datalist, responsive export toolbar; behavioral tests.
- [x] Parent: review changes, Python/JS suite, pip check, synthetic desktop/mobile browser, actual model experiment evidence, final matrix update and local commit. No push, merge, external deployment or bank-frame disclosure.

**Limits:** Neutral action categories are not legal classes. No unsupported authoritative legal inference. A larger external dataset is admitted only after relevant label mapping and data/weight rights are established. Repeated source transformations are not independent videos. Full factual type/description/normative quality still requires human-confirmed samples and independent camera footage.
