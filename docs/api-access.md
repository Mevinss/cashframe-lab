# Доступ к сайту и API жюри

**Сайт:** [Открыть видеоаудит](https://cashframe-vangogh.tailb541d9.ts.net/)

**API:** `https://cashframe-vangogh.tailb541d9.ts.net/api/v1/`

**Ключ:** приватный `local/jury-access.md`, выданный командой для этого HTTPS-сервера. Для сайта и API используется одно значение.

GitHub хранит код; его адрес не является адресом API.

У сайта и API один ключ текущей установки. В браузере его вводят в поле подключения; программный клиент передаёт заголовок `X-API-Key`. Случайный ключ с другого компьютера автоматически не подходит. Действующий секрет хранится только в приватной конфигурации сервера.

## Подготовить Markdown с ключом

На компьютере сервера, из корня проекта:

```powershell
$env:PYTHONPATH = Join-Path $PWD 'src'
.\.venv-isolated\Scripts\python.exe scripts/export_jury_access.py --base-url https://cashframe-vangogh.tailb541d9.ts.net/
```

При другом окружении замените `.venv-isolated`. Команда использует существующий эффективный ключ, проверяет его на `/api/v1/system` и создаёт **`local/jury-access.md`** с адресом, ключом и результатом проверки. Загруженные видео и задания не читаются. Ключ не выводится в терминал, не генерируется заново и не попадает в Git. Передайте файл напрямую уполномоченным участникам и жюри.

Если участница передала отдельный ключ именно для HTTPS-установки, сохраните его в приватный `local/https-api-key.txt` и явно выберите этот файл. Настройки локального сервиса останутся прежними:

```powershell
.\.venv-isolated\Scripts\python.exe scripts/export_jury_access.py --base-url https://cashframe-vangogh.tailb541d9.ts.net/ --key-file local/https-api-key.txt
```

Ответ 401 означает, что ключ не принят этим сайтом. Укажите согласованное значение `CASHFRAME_API_KEY` в приватном `.env.local` сервера, перезапустите backend и повторите проверку. Сетевая ошибка означает, что доступ не подтверждён. Не передавайте такой файл как проверенный доступ.

При ошибке TLS/HTTPS запрос ещё не достиг проверки ключа. На компьютере размещения проверьте запущенный backend (`/health/ready`) и состояние существующего Tailscale Funnel, затем повторите команду. Не отключайте проверку сертификата и не меняйте ключ только из-за сетевой ошибки.

## API

| Запрос | Результат |
|---|---|
| `GET /health/ready` | Готовность без ключа |
| `GET /api/v1/system` | Проверка ключа и профиля модели |
| `POST /api/v1/analyze` | Multipart-файл в поле `file`; ответ 202 и `job_id` |
| `GET /api/v1/jobs/{job_id}` | Состояние и финальный JSON |
| `GET /api/v1/jobs/{job_id}/report.pdf` | Предварительный PDF-акт |
| `GET /api/v1/jobs/{job_id}/passport` | Паспорт доказательств |

Все `/api/v1/` запросы выше требуют `X-API-Key` или действующей браузерной сессии. Для жюри используйте заголовок. Ключ не передаётся параметром URL.

В финальном JSON `verdict` равен `violation` или `no_violation`. Ошибка обработки имеет `status: failed` и не считается отсутствием нарушения. Работоспособность API не подтверждает качество классификатора.

Обновление сервера и сравнение с локальной версией: [синхронизация](sync-deployment.md). Состав приватных весов: [подготовка команды](team-setup.md).
