# Запуск и размещение

Проверено локально на Windows/Python 3.11/CPU. Один процесс Uvicorn и один ограниченный worker. Несколько Uvicorn workers не включать: каждый получит собственный слот и модель, что превышает доступную память. Видео, веса, аннотации и секреты переносятся отдельно по разрешённому приватному каналу.

Подготовка и обучение — в README. Запуск: `scripts/start.ps1`. По умолчанию 127.0.0.1:8000, readiness `/health/ready`. Ключ хранится в исключённом из Git `local/api-key.txt` или переменной окружения. Подготовка весов и установка выполняются заранее; runtime не скачивает модели.

Для внешнего доступа необходимы согласованный хост, HTTPS reverse proxy, ограничение размера запросов 101 МБ и закрытое хранение ключей. Хост и домен не предоставлены, публичное размещение не выполнено. Не публикуйте каталог local и датасет. Ключ для жюри передаётся отдельно; в frontend он не встроен.

Параметры запуска: `scripts/start.ps1 -Bind 127.0.0.1 -Port 8000`. Внешний bind применяют только после настройки защиты и доступа. API-медиа требует ключ, браузер использует авторизованные blob, ключа в URL нет.

Для переноса автономного сервиса подготовьте зависимости, FFmpeg, `local/encoder` и `local/experiment`, затем повторите отдельный smoke-клиент. Команду `prepare-encoder` в изолированном контуре без подготовленных материалов не запускать.
