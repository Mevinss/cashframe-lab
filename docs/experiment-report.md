# Результат обучения перед разработкой интерфейса

Эксперимент выполнен 17 октября 2026 года локально на CPU. Данные: 40 уникальных источников; разбиение 24/8/8, seed 42, точные дубли сгруппированы. Все источники относятся к ограниченной постановочной сцене; независимость связанных сцен и новый ракурс не проверены.

## Что реально обучено

Стандартный DINOv2 ViT-S/14 остаётся замороженным. Извлечено 4 892 визуальных вектора с входом 168×168 и шагом не меньше 0,25 секунды. Из-за исходных временных меток фактическая плотность некоторых записей чуть ниже 4 FPS. Признаки временных окон включают среднее, разброс и скорость изменения визуальных векторов. Положительными являются только окна рядом с точечной разметкой; остальные участки положительных видео не размечаются автоматически.

Обучены веса регуляризованного линейного классификатора: 250 шагов Adam для каждого из трёх значений регуляризации. Сохранены конфигурация, потери по итерациям, исходное разбиение, коэффициенты и порог. Дополнительно проверен обучаемый классификатор агрегатов целого видео; он не улучшил валидационный F1 и не включён в сервис. Загрузка энкодера не называется обучением.

## Сравнение

| Вариант | Выборка | Precision | Recall | F1 | TN / FP / FN / TP |
|---|---|---:|---:|---:|---|
| Замороженные признаки, расстояние до нормальных обучающих окон | validation, 8 видео | 0,50 | 1,00 | 0,67 | 0 / 4 / 0 / 4 |
| Обученный классификатор окон | validation, 8 видео | 0,50 | 1,00 | 0,67 | 0 / 4 / 0 / 4 |
| Исходный вариант | test, 8 видео | 0,50 | 1,00 | 0,67 | 0 / 4 / 0 / 4 |
| Обученный вариант | test, 8 видео | 0,50 | 1,00 | 0,67 | 0 / 4 / 0 / 4 |

Оба варианта пометили положительными все восемь тестовых видео. **Полезность обнаружения пока не доказана; результат недостаточен для эксплуатации.** Precision/F1 не улучшились. Средняя ошибка пикового таймкода по четырём размеченным положительным test-видео: 4,375 секунды у исходного варианта и 3,875 секунды у обученного. Это приближение по точечной разметке, а не проверка релевантности доказательств.

Пороги и варианты выбирались только по validation. После первого отчёта проверена гипотеза с агрегатом видео; она отвергнута по validation. Итоговые test-показатели рассчитаны повторно для аудита сохранённой версии, поэтому этот набор нельзя представлять как никогда ранее не просмотренный в будущих исследованиях. Для следующей итерации нужен новый внешний отложенный набор.

Исходный вариант использует неизменённый энкодер и обучающие нормальные эталоны; это не семантическое zero-shot распознавание кассовых нарушений. Требование отдельного семантического pretrained baseline остаётся невыполненным.

## Скорость и ограничения

Извлечение признаков всех 40 источников заняло суммарно 596,15 секунды. У самого длинного ролика 142,53 секунды извлечение заняло 57,23 секунды. Это время только одного этапа; полное API-время проверяется отдельно и сохраняется в acceptance-отчёте. На машине нет CUDA GPU.

Подтверждённые типы событий отсутствуют. Бинарный сигнал не утверждает конкретное наблюдаемое действие и не получает автоматически нормативное основание. Человек должен подтвердить типы и интервалы через локальную аннотацию; затем требуется отдельное обучение/оценка типов. Качество доказательств человеком, потери действий короче шага выборки, перекрытия и смена ракурса не оценены. Утверждать готовность решения ко всем требованиям кейса нельзя.

Все частные веса, исходные результаты, per-video ошибки, журналы и манифесты находятся только в `local/`. В Git входит этот агрегированный отчёт и воспроизводимый код. Исходный эксперимент сохранён отдельно в `local/experiments/v1-window-only`.
